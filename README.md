# <img src="icons/icon128.png" width="36" height="36" alt="Style Scope icon" align="center" /> Style Scope

一个 Chrome 扩展：悬停网页元素即可查看其计算样式、盒模型、内嵌间距与对象间距离。

## 功能

- 悬停预览，点击锁定元素
- 可在扩展面板选择浮层或浏览器原生侧边栏；侧边栏按标签页保留最后一次选中结果
- 使用接近 Figma 属性侧边栏的紧凑排版，按 Layout、Typography、Fill、Stroke、Effects 分组并支持折叠
- 只展示设计师关心且实际生效的属性；自动隐藏默认值、空值、透明填充和零值边框
- 合并显示四边相同的 padding、圆角和描边，字体只展示当前首选字体
- 颜色详情只显示样式声明真实引用的 `SOURCE TOKEN`，不罗列同色候选变量
- 直接标注 margin、border、padding、content，以及图标与文字之间的 `gap`
- 选中对象后悬停另一个对象，显示 `X / Y` 边缘距离
- 父子包含关系显示 `T / R / B / L` 四边内嵌距离
- 选中资源后预先读取，后台失败时回到页面环境读取；支持 CDN、登录态同源资源、`blob:` 图片与 Canvas
- 外链图片保留原始字节和 MIME，不进行 PNG 转码
- SVG 保留原始源码，同时提供 `image/svg+xml`、`text/html` 与 `text/plain` 剪贴板表示，不生成 PNG
- Canvas 没有原始文件编码，因此仍以 PNG 导出
- 系统剪贴板不支持资源原始格式时直接提示失败，不自动降级或改变格式
- 面板开关、展示模式与 `⌘ + E` 使用同一状态并实时同步；侧边栏模式会随检视开关打开或隐藏，选中元素时也会自动唤起
- `Esc` 立即退出

## 安装

1. 打开 `chrome://extensions`
2. 开启「开发者模式」
3. 选择「加载已解压的扩展程序」
4. 选择本项目目录

## 使用

先在扩展面板选择「浮层」或「侧边栏」。按 `⌘ + E` 开关检视，按一次开启，再按一次关闭；`Esc` 也会立即退出。开启后移动鼠标预览元素，点击即可锁定，点击其他元素可重新选择。侧边栏模式只移动信息面板，网页中的元素描边、盒模型和距离标注保持不变。

## 本地演示

运行任意静态服务器后打开 `demo.html`。例如：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/demo.html`。
